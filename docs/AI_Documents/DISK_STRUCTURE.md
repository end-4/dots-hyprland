# Disk Structure Recommendation

For a clean, production-grade workspace, adopt the following structure:

```
/home/user/
├── Work/               # Professional projects, work documents
│   ├── Projects/
│   └── Documents/
├── Personal/           # Personal projects, side-hustles, learning
│   ├── Auto-desktopenv/
│   ├── AI_Experiments/
│   └── Notes/
├── Media/              # Photos, videos, music
├── Backups/            # Automated backups from smart-organizer
└── Tools/              # Locally compiled or user-specific binaries
```

*Update smart-organizer config to automatically target and categorize files into these directories based on filetype or project markers.*
